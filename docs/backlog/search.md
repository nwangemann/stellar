# 5. Search with an arrow

Goal: find an object by name and be led to it.

- [ ] **5.1 Matching.** Pure search over stars, constellations and bodies, with tests. Read: `src/core/catalog/`.

- [ ] **5.3 Arrow.** Pure direction math, including behind the viewer, then an edge arrow that ends on lock-on. Read: `src/core/projection/`, `SkyScreen.tsx`.
