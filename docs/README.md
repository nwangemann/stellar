# Stellar docs

## Quick start

1. Node 22.13+, 24.3+ or 26+. Xcode and CocoaPods for iOS. On this Mac, set the path shown in the `stellar-dev` skill first.
2. `npm install`
3. `npm run ios` builds and runs on the simulator. `npm run web` opens the development preview. `npm run android` is configured but untested.
4. `npm run check` before every commit.
