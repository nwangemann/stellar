# Standards

- Strict TypeScript; use branded units at every boundary.
- Components PascalCase, modules camelCase, one system doc per feature folder.
- Colors, spacing and type sizes come from tokens. Touch targets are at least 44 points.
- Core logic has unit tests next to it.
- Conventional Commits. `npm run check` must pass.
- A change to core, features, dependencies or standards updates its doc in the same change.
